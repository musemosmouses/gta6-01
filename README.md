Surya Bay — an original open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police at wanted levels 0–5, run 5 chained story missions plus taxi and delivery side jobs, and fight rival crews.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move, mouse to look, E to enter/exit cars, F to punch, click to shoot, R to reload, P to pause.
